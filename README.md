# IoT Assistant

IoT-only AI chatbot using Flask and Google Gemini.

## Structure
app.py
config.py
requirements.txt
.env
.gitignore
README.md
templates/index.html
static/style.css
static/script.js

## Setup
1. Install Python.
2. Open PowerShell in this folder.
3. `python -m venv venv`
4. `.env\Scripts\Activate.ps1`
5. `pip install -r requirements.txt`
6. Put your Gemini API key in `.env`.
7. Run `python app.py`.
8. Open http://127.0.0.1:5000

## Examples
Allowed: IoT, sensors, ESP32, Arduino for IoT, MQTT, smart agriculture, IoT projects.
